# Data and code availability — draft

The headline results in this manuscript do not depend on a newly collected empirical dataset. They are generated from declared finite ecological world sets, observation/failure contracts, exact enumeration and deterministic simulations implemented in the accompanying code.

The reproducibility package will contain the source code required to reconstruct the compatible-world and target-safe quotients, failure-architecture calculations, exact learning-versus-licensing benchmark, risk-limited policy evaluations, manuscript tables and figures, together with automated tests and deterministic replay instructions.

At peer review, the code package will be provided in the form required by the journal's current review policy. A permanent public archival snapshot and persistent identifier will be fixed no later than the publication-stage data/code availability requirement. The final statement will name the archive and DOI once that version-of-record snapshot has been created.

No external empirical dataset is required to reproduce the manuscript's headline quantitative claims. Any illustrative ecological scenarios are model examples and are labelled as such rather than presented as natural-system validation.
